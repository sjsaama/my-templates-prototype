## Concepts (clarified)

### STATIC
A section that is **not AI-generated** — fixed / locked content (or fixed framing text).  
Old prototype tooltip: *“Static section — fixed text only. Its content is not generated by AI.”*  
Examples in mocks: HPI, Labs and Imaging (lock + **Static** badge).

Related but different: **Static Start / Static End** = fixed boilerplate before/after a section’s body. The model never rewrites those strings.

### EHR Pull (ghost row)
A section that is **pulled into the note from the EHR**, not generated or pushed by Marvix.  
Old prototype: Vitals with badge **“Inserted by EHR Pull”** — no EHR mapping chip; enable toggle only.  
Tooltip: *“This section is pulled directly from the EHR and is not generated by the template.”*

Sibling concept: **Inserted by File Upload** (same “not generated by template” idea, different source).

**Open:** Keep STATIC badge + EHR Pull row in the AMD mock, or drop them?
