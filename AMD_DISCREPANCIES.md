## Footnotes — dropped / superseded

† **STATIC (dropped)**  
Section marked as not AI-generated (fixed/locked content). Old tooltip: *“Static section — fixed text only. Its content is not generated by AI.”* Examples: HPI, Labs.  
Do not confuse with **Static Start / Static End**, which remain in Output & EHR as fixed boilerplate around generated content.

† **EHR Pull / File Upload (dropped)**  
Ghost rows for content that comes *into* the note from AMD (Vitals — “Inserted by EHR Pull”) or from an uploaded file. Not generated or pushed by Marvix; enable only, no mapping. Removed from this prototype.

†† **`Clinical Notes > snake_case` path style (superseded)**  
Older design chips used this format. AMD prototype now uses **`Office Visit > Title Case`** only.
