# My Templates prototype

Doctor-facing template editor prototype + product docs.

## Layout

| Path | Purpose |
|---|---|
| `index.html`, `My Templates.html`, `*.jsx`, `design-tokens.js` | Runnable prototype |
| [`MY_TEMPLATES_PRD.md`](MY_TEMPLATES_PRD.md) | Canonical product decisions |
| [`ehr_mapping/`](ehr_mapping/) | Per-EHR mapping reference (active EHRs) |
| [`ehr_mapping/not_needed/`](ehr_mapping/not_needed/) | Archived EHR / shared docs (not deleted) |
| [`docs/`](docs/) | Supporting backend, design-PR, and log-analysis notes |
| [`design_assets/`](design_assets/) | Figma + design screenshots (not used at runtime) |

Open `index.html` or `My Templates.html` in a browser to run the prototype.
